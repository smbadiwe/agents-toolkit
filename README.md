# agents-toolkit

A collection of tools I use for my coding and research agents.

## Installation

```
npx skills add smbadiwe/agents-toolkit --skill [SKILL_NAMES]
```

For more than one `SKILL_NAMES`, separate with space.

### View all skills in this repo

```
npx skills add smbadiwe/agents-toolkit --list --full-depth
```

| Skill | Install |
|-------|---------|
| dotnet | `npx skills add smbadiwe/agents-toolkit --skill dotnet` |
| [LID](skills/lid/README.md) | `npx skills add smbadiwe/agents-toolkit --skill lid-setup map-codebase arrow-maintenance linked-intent-dev` |
